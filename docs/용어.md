# 용어

이 저장소의 문서와 작업 보고에서 쓰는 이름이다. 한 대상은 한 이름으로만 부른다.

| 쓰는 이름 | 뜻 | 쓰지 않는 이름 |
|---|---|---|
| 엔진 | `modern/SSAMDLL/`의 분석 DLL (`SSAMDLL_MT.dll`) | 분석 모듈, 코어 |
| 콘솔 프로그램 | `modern/SSAMDLL/bin/SSAM_MT.exe` | CLI 툴, 명령줄 엔진 |
| 화면 프로그램 | `modern/SSAM3/WorkingDir/SSAM3M.exe` | GUI 앱, 메인 앱 |
| TRJ 파일 | 시뮬레이션이 내보낸 차량 궤적 이진 파일 | 궤적 데이터, 입력 파일 |
| 차량 기록 | TRJ 파일의 VEHICLE 레코드 1건. 한 차량의 한 시간 단계 상태 | 차량 데이터, 레코드 |
| 시간 단계 | TRJ 파일의 TIMESTEP 레코드 1건과 그 뒤의 차량 기록 묶음 | 스텝, 프레임 |
| 연결 | 앞 시간 단계의 차량 기록이 같은 차량의 다음 시간 단계 기록을 가리키게 하는 일 | 링크(도로 링크와 헷갈림) |
| 투영 | 차량 기록의 최대 TTC 뒤 예상 위치 | 예측 위치, 프로젝션 |
| 상충 후보 | 투영이 서로 겹친 차량 쌍 (코드의 `Event`) | 이벤트 |
| 상충 | 확정된 상충 후보 (코드의 `Conflict`). 결과 CSV의 한 줄 | 충돌, 컨플릭트 |
| 결과 CSV | `csvfile=`로 내보내는 요약 통계와 상충 목록 | 출력 파일 |
| TRJ 텍스트 파일 | `-dat` 옵션(화면: TRJ를 텍스트로)이 만드는 `<TRJ이름>_dat.csv` | dat 파일 |
| 읽기 스레드 | 분석과 동시에 TRJ 파일을 읽는 전용 스레드 | 리더, I/O 스레드 |
| 분석 스레드 수 | 스레드 수 칸(`nthreads=`)의 숫자. 충돌 계산에 쓰는 스레드 수. 읽기 스레드는 세지 않는다 | 스레드 수(단독으로 쓸 때) |
| 검증 출력 | 환경변수 `SSAM_VERIFY_DUMP`로 켜는, 상충별 P(UEA)·mTTC·mPET 값 파일 | 덤프 |
| 기준 빌드 | 동작을 바꾸기 전의 엔진 빌드 | 원본 빌드 |
| 기준 결과 | 기준 빌드가 만든 출력 파일의 SHA-256 값 (`.local/baseline/baseline.json`) | 정답 파일, 골든 |
| 검증 스크립트 | `scripts/verify-engine.ps1`. 출력 파일을 기준 결과와 비교한다 | 테스트 |
